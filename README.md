# Skärminspelare

Skärminspelare i en enda HTML-fil. Körs helt i webbläsaren, inget laddas upp.

- Välj skärm, fönster eller flik
- Mikrofon, systemljud och webbkamera som rund bubbla
- Paus och nedräkning
- Sparar MP4 (WebM i Firefox)

## Använda
Ladda ner `index.html` och öppna den direkt i Chrome, Edge eller Safari.
Den måste öppnas som en egen sida, inte i en förhandsvisning, annars blockeras skärmdelning.
